# Naeem AI — Android PWA starter

نسخة أولى مجانية قابلة للتثبيت على Android كتطبيق ويب تقدمي (PWA).

## ما الذي يعمل الآن؟
- واجهة محادثة عربية/إنجليزية.
- ربط مباشر بـ Gemini API.
- إدخال صوتي عبر Speech Recognition عندما يدعمه المتصفح.
- قراءة الردود صوتياً عبر Speech Synthesis.
- قائمة مهام محلية على الجهاز.
- واجهة قابلة للتثبيت وتعمل دون اتصال لفتح التطبيق (المحادثة تحتاج إنترنت).
- رسائل المحادثة لا تُحفظ بعد إغلاق الصفحة في هذه النسخة؛ المهام ومفتاح API محفوظان محلياً.

## تشغيله مجاناً على Android
1. نزّل ملفات المشروع وارفع محتويات المجلد إلى مستودع GitHub جديد.
2. من GitHub افتح **Settings → Pages**.
3. اختر **Deploy from a branch** ثم `main` و`/ (root)` واحفظ.
4. انتظر رابط الموقع الذي ينتهي بـ `github.io`.
5. افتح الرابط في Chrome على هاتف Android.
6. من قائمة Chrome اختر **Install app** أو **Add to Home screen**.
7. افتح Naeem AI ثم ⚙ وأدخل مفتاح Gemini API.

## الحصول على مفتاح Gemini
- افتح Google AI Studio: https://aistudio.google.com/app/apikey
- سجّل الدخول وأنشئ API key.
- أدخله في إعدادات التطبيق.
- حدود الاستخدام المجاني وتوفر النماذج تختلف حسب البلد والحساب وتتغير؛ راجع صفحة الأسعار والحدود في Google AI Studio.

## الأمان
هذه نسخة شخصية تجريبية. مفتاح API محفوظ في `localStorage` داخل المتصفح ويُرسل إلى Google عند طلب الرد. لا ترفع المفتاح إلى GitHub ولا تشاركه. إذا كان الهاتف مشتركاً أو غير آمن فلا تحفظ المفتاح عليه. للاستخدام العام أو لعدة مستخدمين يجب نقل استدعاء Gemini إلى خادم وسيط آمن مع حماية المفتاح وتحديد الاستخدام.

## حدود النسخة الأولى
- لا يوجد بحث حي مستقل على الويب داخل التطبيق حتى الآن.
- لا يرسل رسائل WhatsApp أو بريد إلكتروني.
- لا يتحكم بتطبيقات الهاتف ولا ينفذ مدفوعات.
- لا ينشئ ملفات Word/Excel/PDF بعد؛ يمكن إضافتها في المرحلة التالية.
- الصوت يعتمد على دعم Chrome/Android للغة العربية أو الإنجليزية وقد تختلف الأصوات المتاحة.

## الملفات
- `index.html`: واجهة التطبيق.
- `styles.css`: التصميم.
- `app.js`: المحادثة والصوت والمهام.
- `manifest.webmanifest`: تعريف PWA.
- `sw.js`: التخزين المؤقت للعمل دون اتصال.
- `icons/`: أيقونات التطبيق.
